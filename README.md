# Argentina — Omarchy theme

A dark Omarchy theme inspired by Argentina — its flag, skies, and urban light: deep navy surfaces, celeste accents, and warm gold.

![preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/santiagoei/omarchy-argentina.git
omarchy theme set argentina
```

## Palette

| Token | Color | Inspiration |
|---|---|---|
| accent | `#75aadb` | Celeste |
| background | `#0c1c30` | Noche argentina (navy) |
| foreground | `#eaf1f8` | Blanco |
| yellow | `#f6b40e` | Oro cálido |
| green | `#63c7a3` | Pampa verde |
| red | `#e57382` | Papel picado |
| brown | `#8a6a48` | Yerba mate |

Window borders use a celeste→white gradient, like the stripes of the Argentine flag.

## Backgrounds

20 photos of Argentina — Buenos Aires (the Obeliscos, Congreso, Caminito,
the neighborhoods, Mar del Plata), Iguazú, El Calafate, Aconcagua, Los
Alerces, Jujuy's Siete Colores, the seven lakes of Neuquén,
Córdoba, a map, and a Buenos Aires mural. Filenames carry their priority tier,
so the alphabetical cycle runs first-pick first: `01_arg_bsas_obelisco.webp`
opens the theme. The light sister shares this exact pool, renumbered
around its own opener.

## Sister theme

[omarchy-argentina-light](https://github.com/santiagoei/omarchy-argentina-light.git) — the light variant: celeste and white.
